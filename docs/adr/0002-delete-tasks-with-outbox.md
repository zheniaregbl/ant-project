# 0002. Удаление объектов с помощью записей в outbox

### Дата
2026-09-03

### Статус
Принято

### Контекст
В приложении, при работе без сети, можно удалить задачу, проект или тег. При синхронизации с сервером
важно понимать какие объекты были удалены, чтобы передать информацию о них.

### Решение
Таблица outbox хранящая тип, id объекта и время удаления. Запись в outbox создаётся в той же транзакции,
что и удаление; удаляется после подтверждения сервером; для объектов с serverVersion == null запись
не создаётся вовсе — серверу нечего сообщать.

### Последствия
Таблицы объектов чистые, ни один запрос не будет проверять время удаления, не получится, забыв указать 
условие, показать удаленный объект. Каскадное удаление работает нормально, потому что удаление объектов
физическое. Удаление - две операции, само удаление и запись в таблицу. Данные удаленной задачи 
не восстановить, отмену удаления придется реализовывать при управлении на UI, делать таймер ожидания,
что пользователь передумает.

### Рассмотренные альтернативы
Колонка deletedAt побуждает к созданию условий при каждом запросе. Удаление только online ломает
offline-first идеологию.
