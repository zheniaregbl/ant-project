# 0014. SVG-иллюстрации через Coil 3

### Дата
2026-10-29

### Статус
Принято

### Контекст
Пустым состояниям нужны иллюстрации. Макет сделан в Figma, оттуда они выгружаются как SVG.
В Compose Multiplatform нет общего формата векторной графики: Android понимает vector drawable,
на остальных платформах его нет, а ручной перевод SVG в ImageVector трудоёмок и ломается при
каждой правке макета.

### Решение
Иллюстрации хранятся как исходные SVG в ресурсах :core:designsystem и отображаются через Coil 3
с модулем coil-svg.

### Последствия
Выгрузка из Figma попадает в проект как есть, без промежуточных преобразований, и обновление
иллюстрации — это замена файла. Одни и те же файлы работают на всех трёх платформах.
Ценой идёт парсинг SVG в рантайме вместо компиляции в код и ещё одна зависимость в design system.
Для сложных иллюстраций первый показ может быть заметно не мгновенным, поэтому пустое состояние
должно корректно выглядеть и до загрузки картинки.

### Рассмотренные альтернативы
Конвертация в vector drawable — работает только на Android. Ручной перевод в ImageVector — код
вместо ресурсов, правка макета означает переписывание руками. Растровые PNG — вес и потеря
качества на разных плотностях.
