# 0001. Клиентское время по updatedAt, конфликты по serverVersion

### Дата
2026-09-03

### Статус
Принято

### Контекст
Приложение оффлайн-first, изменения задачи могут происходить на разных устройствах без подключения
к сети, при синхронизации данных с сервером важно понимать свежесть записи и решать конфликты.

### Решение
updatedAt хранится как Long, epoch millis UTC. Заполняется клиентом при любой мутации. Разрешение 
конфликтов идёт по serverVersion, инкрементируется только сервером; updatedAt — вторичный критерий.

### Последствия
Правка работает полностью оффлайн. Параллельные изменения обнаруживаются надежно, потому что счетчик
редакций не зависит от часов. При совпадении версий задачи выигрывает тот у кого спешат часы.

### Рассмотренные альтернативы
Серверное время — недоступно в оффлайне. Одно updatedAt без serverVersion — конфликты 
определялись бы часами, а они врут.
