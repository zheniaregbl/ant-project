# 0006. Проверка границ модулей в build-logic

### Дата
2026-09-12

### Статус
Принято

### Контекст
Структура модулей описана схемой: фича зависит только от :core:domain, :core:database не знает
о домене, фичи не зависят друг от друга. Схема в README не исполняется, и в спешке её легко
нарушить — особенно в одиночной разработке, где некому заметить это на ревью.

### Решение
Convention-плагин проверяет зависимости модуля на этапе конфигурации и бросает GradleException
при нарушении. Для модулей с префиксом :feature: запрещены зависимости на другие :feature:.

### Последствия
Нарушение правила роняет сборку, а не остаётся незамеченным. Архитектурная схема перестаёт быть
декларацией и становится фактом, гарантированным сборкой. Проверка работает на этапе конфигурации,
поэтому немного замедляет синк. При добавлении нового правила приходится править build-logic,
а он кешируется агрессивно и требует остановки демона.

### Рассмотренные альтернативы
Соглашение в документации — не исполняется. Konsist или ArchUnit — дают более выразительные
правила, но это ещё одна зависимость и отдельный прогон; для трёх простых правил избыточно.
