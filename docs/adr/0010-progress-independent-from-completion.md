# 0010. progress зависит только от подзадач, выполнение проставляется вручную

### Дата
2026-09-24

### Статус
Принято

### Контекст
У задачи может быть чек-лист подзадач. Возникает вопрос, связаны ли закрытие подзадач и выполнение
самой задачи: считать ли задачу выполненной автоматически при закрытии всех подзадач и что
показывать в прогрессе у задачи без подзадач.

### Решение
progress — nullable, равен доле закрытых подзадач и существует только при наличии подзадач.
Без подзадач это null, а не ноль и не единица. Выполнение задачи проставляется пользователем
вручную и от подзадач не зависит: задачу можно закрыть с незакрытыми подзадачами и оставить
открытой при всех закрытых.

### Последствия
UI отличает «нет чек-листа» от «чек-лист пустой» и не рисует полоску прогресса там, где её смысла
нет. Пользователь не теряет контроль: закрытие последней подзадачи не закрывает задачу за него,
а оставшаяся мелочь не мешает закрыть задачу целиком. Прогресс — вычисляемое свойство, в базе
не хранится и не может разойтись с подзадачами. Поведение неочевидно для части пользователей,
привыкших к автозакрытию.

### Рассмотренные альтернативы
Автоматическое выполнение при закрытии всех подзадач — пользователь теряет контроль, а добавление
новой подзадачи к выполненной задаче должно было бы её воскрешать. progress равный нулю без
подзадач — UI не отличит пустой чек-лист от его отсутствия.
