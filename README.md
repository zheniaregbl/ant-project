# Трекер задач

Пет-проект: трекер задач с прицелом на дальнейшее расширение функциональности. За основу
взят классический todolist, поверх которого добавляются небольшие улучшения.

> Статус: **идея / ранняя проработка**. Стек и целевые платформы определены, конкретные фич-лист
> и риски ещё уточняются.

## Идея

Todolist с акцентом на удобство ввода задач.

## Платформы и стек

- **Kotlin Multiplatform (KMP)** — общая бизнес-логика
- **Compose Multiplatform (CMP)** — общий UI
- Целевые платформы: **Android, iOS, Desktop** — планируется покрыть все три уже в первом релизе, без поэтапного раскатывания по платформам

## Ключевая фича

- 🎙 Голосовой ввод задач — главное отличие от типовых todolist-приложений
> Функция еще не готова. Определяется вектор реализации фичи
